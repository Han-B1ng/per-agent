# 引擎性能基准

对 [`web/engine.js`](../web/engine.js) 的 `computeAll` 做手动性能基准。脚本用固定种子生成模拟账本，分别测 1,000 和 10,000 条事件；两种规模先交替预热 10 轮，再交替计时各 50 次，报告平均耗时与 P95。脚本无外部依赖，只读取引擎、不写任何文件。

在 `p0-delivery/` 下运行：

```sh
node benchmarks/engine-benchmark.mjs
```

输出会附带 Node 版本、系统、CPU 与内存信息，以及账本参数（固定种子、730 天窗口、固定 `today`）。不同机器的绝对值不能直接比较；比较改动前后性能时，请在同一台机器上重复运行。
