# 赛事要求 — 2026 Qoder 高校创造力大赛

> 调研日期：2026-11-16。以官方最新公告为准。
> 官方赛题页：https://tianchi.aliyun.com/competition/entrance/532536

## 基本信息

- 主办：Qoder｜赞助：NVIDIA｜奖金池：¥88,500
- 参赛对象：全国在校大学生（本/专科、硕博，含港澳台），不限专业
- 组队：1–3 人｜提交份数不限｜每队限获一项现金奖
- 本项目团队：2 人（共同定 idea，实现由一人 + Qoder 完成）

## 关键时间（截止 11/30 18:00）

| 环节 | 时间 |
| --- | --- |
| 报名与组队 | 10/29 — 11/30 18:00 |
| 发布作品（论坛发帖） | 10/29 — 11/30 18:00 |
| 初筛 | 12/1 — 12/7，每赛道筛 14 队进决赛，共 42 队 |
| 决赛及奖项公布 | 12/1 — 12/15，线上直播路演 |

## 赛道

| 赛道 | 方向 | 官方示例 |
| --- | --- | --- |
| StudyHack 学习科研 | 科研/学习场景 | 文献综述、实验数据处理、智能体、多模态、RAG 问答、科研 Copilot、Agent 工作流、课件知识库、课表作业管理 |
| LifeHack 生活娱乐 | 生活/社团/娱乐 | AI 剧本、表情包工厂、音乐视觉实验、生活小工具、互动叙事与生成式玩具、能在浏览器里玩 3 分钟的东西 |

三赛道分别评分、分别设奖，共用同一套赛程与报名表单。

## 硬性要求（最容易踩坑）

1. **开发与部署均由 Qoder 完成**，作品帖需说明使用过程。
2. **必须部署到 Qoder Sites 并设为公开访问**（`xxx.qoder.zone`），评委点开就能用。原则上不接受本地文件、压缩包。
3. **必须原创**，不得抄袭或搬运。
4. **11/30 18:00 前在天池赛题页论坛发帖**，必含五部分：
   - 自我介绍
   - 你的作品是什么（一句话说清谁在什么场景下用）
   - 为什么做（问题或想法的来源）
   - 怎么用（5 步以内，评委照着能自己打开用起来）
   - 用 Qoder 做出来的过程（哪几步交给它、你改了什么，尽量多截图凭证）
5. 可选加分：小红书/抖音/视频号分享链接，**标题需带「2026 Qoder 高校创造力大赛」**。
6. 内容需符合活动主题、社区规范与法律法规。

## 认证（未完成则取消获奖资格）

所有参赛成员需在初赛截止前完成：

1. 天池平台实名认证（个人中心 → 支付宝实名认证）
2. 阿里云大学生认证

学生认证后可领取 Qoder CN 一个月免费权益：https://university.aliyun.com/action/qoder

**待核实**：该权益落在哪个档位，是否支持 Sites 的 database / storage / Cloud Agents。个人 Free 版只支持静态部署。

## 已发布作品（避免撞车）

表情包工厂、3D 键盘拆解、互动小说创作台 DreamChord、割草游戏「无敌奶蛙大王」、人生模拟器、宿舍漫画「今晚八点档」、「不烧心」互动游戏、科研记忆 Lumina、信号与系统分析平台、室内拍照指路。

## 从优秀作品观察到的评审偏好

- 点开即玩，无需注册、无需安装
- 桌面 + 手机都适配
- 控制台 0 报错
- 一个真实具体的痛点故事
- 诚实的过程记录：「哪几步交给 Qoder、我改了什么」
- 数据本地优先被当作卖点写进帖子
- 允许「持续更新中」，核心玩法完整可玩即可
