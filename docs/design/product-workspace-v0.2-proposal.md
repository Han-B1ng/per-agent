# 个人成长指数 v0.2 产品工作台

设计提案。行情是默认主页，目标中心和成长记录是侧栏另外两个入口。业务规则沿用 D18–D40，桌面交互以已确认的 P0 样板为准。

## 三个主入口

| 页面 | 内容与动作 |
| --- | --- |
| 行情 | 总指数、周 K、样例／我的、底部对话。点周 K 打开右侧抽屉看计算明细，明细能定位原始记录。 |
| 目标中心 | 默认显示全部目标和任务，按「未完成」「已完成」分组，两组同时可见。未完成覆盖进行中、逾期、暂停，已完成按完成时间倒序。可以筛选、查看到期日与仓位、完成任务、查看关联记录和计分历史。通过底部对话新增，保留明确的新增入口。 |
| 成长记录 | 按发生日期倒序展示行为、情绪、休息和任务完成等变化。支持日期、类型和关键词筛选。待确认事件和休息在列表内显式标记，可补充、确认或否认。记录详情展示原文和计分，提供修正和撤销入口。 |

目标中心关注每件事现在的状态。成长记录关注什么时候发生了什么。同一任务的状态、完成记录和走势明细通过稳定 ID 互相定位。进行中的任务留在目标中心，已经发生的创建或状态变更可以作为有日期的记录展示，避免把待做事项当成已发生的行为计分。历史任务和记录均可查询，列表可以折叠、分页或筛选。

## 页面交互

- 桌面左栏只列三个主入口，可收起。窄屏从菜单进入。详情按需用抽屉展示。
- 行情发送前只显示完整行情与底部单行输入，点击或聚焦输入框只改变聚焦样式；首次发送后在输入框上方展开消息、历史与快捷提示，消息放得下时行情与输入框保持原位；消息实际溢出时卡片底色、边框与工具栏退场，仅原周 K 绘图区放大渐隐、过渡后静止且绘图区高度不跳变，页头保留点位、涨跌幅与返回行情，消息区独立滚动、输入框固定底部；返回行情保留消息与草稿。样例页闲聊不切换数据视图，只有账本写入后才切到「我的」。布局与视觉以 P0 和 Dk Connect 为参照。
- 可在行情顶部或导航角落放模型连接状态和设置。导出与清空本机记录收在设置里。待确认归入成长记录，周回顾通过日期筛选和周 K 明细完成。
- 通过对话新增、手动完成、补充确认或撤销后，目标、记录和指数共享同一份本地数据。空态指向明确的下一步，错误能重试且不重复入账。

## 数据与后端

- 浏览器负责版本化本地存储、账本查询、状态更新及确定性计算。样例只读，与个人数据隔离。升级迁移已有普通记录、待确认项和已完成任务。
- 线上继续使用同源 Qoder Sites Function 和 Cloud Agents CN，保留 health、extract 与 reply/items 契约。服务端负责校验、限流、超时和错误映射。模型只抽取，QODER_PAT 留在服务端。保留本地 Mock/Stub。
- 目标采用现有任务语义起步。多层目标拆解、任务暂停或修改到期日的追溯规则如未定，提供场景交负责人确认。D39 保留完成前已结算的逾期，完成日只计一次完成增益；D40 保证待确认事件与休息不影响分数。
- 公开发布仍由负责人安排。私有站点验证真实 extract 成功及结构化结果。

## 验收

1. 首屏默认行情，桌面和窄屏可往返三个入口。双桌面视口复跑已确认的行情到对话过渡。
2. 创建两个任务并完成其中一个，目标中心默认同时显示两组。在成长记录能找到完成条目，能回到目标及周 K 明细；刷新后状态一致。
3. 录入行为、情绪、休息，确认各类记录可筛选。验证待确认与聊天同步，修正或撤销后，历史周 K、明细与目标状态按既有规则更新。
4. 验证旧数据迁移、样例与个人隔离、失败不误入账及真实 Sites 抽取。Mock、Stub 和真实调用分别附证据。
