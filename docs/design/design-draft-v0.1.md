## 1. 产品定位

竞品（陪伴类 AI）卖的是**「被理解」**——情绪价值。
我们卖的是**「被度量」**——把模糊的自我感觉变成可看、可复算的数字。

**一句话**：给想看清自己变化的年轻人，把日常对话变成一支「自己」的股票——你随口说的事被记成事件与持仓，一个可复算的引擎给出成长指数与走势。

关键认知（决定所有设计取舍）：

- **聊天不是产品目的，是摩擦最低的采集入口。** 用户不需要填表、不需要打卡，说一句就完成录入。
- **可视化不是装饰，是指数的可解释界面。** 每一根 K 线都要能点开看「为什么」。
- **24h 在场感靠节律，不靠推送。**

## 2. 核心链路

```
用户说一句话
  → 模型抽取结构化结果（事件 / 任务 / 休息标记 + 极性 + 强度 + 置信度）
  → 前端纯函数引擎立刻算出指数
  → 前端立刻重绘 K 线
  → 写入本地存储
  → 用户看到数字变化，继续对话（闭环）
```

体感目标：**「说一句，图就动了」**。计算必须即时，不能等到某个「结算时刻」才更新。
开盘/收盘只是界面节律，不是计算时机。

## 4. 计算引擎规格（可信度的全部来源）

> 权威口径见 `agent-engine-spec-v0.1.md`。本节为设计侧摘要，数值权重待校准（P4）。

### 4.1 职责切分（不可妥协）

- **模型只做抽取**，输出强 schema JSON，**不产生任何分数**（schema 里没有 score 字段，结构上强制）。
- **引擎是前端纯函数**，固定权重 + 版本化公式，同一输入永远同一输出，可离线复算。
- 理由：模型口算的分会飘，曲线出现无法解释的跳变，评委问「为什么这里涨了」就答不上来，整个立意塌掉。

### 4.2 抽取 Schema

**以 `agent-engine-spec-v0.1.md §6` 为准**，本文不再复制 schema，避免双源漂移。要点：

- 事件含 `id / kind / eventType(behavior|emotion) / polarity / intensity / occurredAt / quote / tags / confidence / status(pending|confirmed) / deletedAt`。
- 任务含稳定 `id / title / dueAt / position / status / createdAt / doneAt / deletedAt`。
- 休息标记 `kind=rest`。
- **无 dimension 字段**（D19）；tags 自由、不参与计分。
- 情绪事件 `eventType=emotion`：polarity 恒 neutral、贡献恒 0、不占同日计分名额（D18）。
- ⚠️ 规格缺口（路由 agent 会话补全）：同日稳定排序键、任务/事件的状态变更操作协议（按 id 引用）。见 §4.5 与 decision-log。

### 4.3 指数公式 v0.1（权重待校准 P4）

基准 1000 点。按日计算，周 K 由日数据聚合。**无维度权重**（D19）。

```
日收益率 r = Σ(事件影响%) + 任务完成增益% − 逾期损耗% + 沉默/停牌项

事件影响%   = sign(polarity) × base[intensity]      // 无 dimensionWeight
base        = [0.2%, 0.5%, 1.0%, 1.8%, 3.0%]        // intensity 1..5，待校准
任务完成增益 = +0.6% × position / 3                  // 完成任务只计此项，不另建事件（D25）
逾期损耗     = −0.4% × position / 3（每日，设上限，引擎按 dueAt 推导）

单日涨跌停   = ±6%（D26）
指数_t       = 指数_{t-1} × (1 + clamp(r, -6%, +6%))
指数下限     = 100 点
波动率       = 近 7 日 r 的标准差
```

沉默与停牌（D20–D24，取代旧「满 2 天一次性 +0.3%」）：

- **主动标记休息 = 停牌**：保护期 7 天，期内不衰减且每日 +0.05%（7 天封顶，一段最多 +0.35%）；第 8 天起保护失效开始衰减。
- **被动沉默**：连续第 4 个无事件日起，每日 -0.1% 衰减。
- 超停牌期限后衰减率与被动沉默相同（-0.1%/天），引擎只有一套衰减逻辑。
- **任何事件（含 neutral 情绪）都打破沉默**并重置连续计数。
- 衰减/停牌加分计入当日 r，参与涨跌停 clamp，明细标注来源（无 quote）。

防刷（D25–D27）：不双重计分 + 同日计分上限 8 条（超出只记录不计分，情绪不占名额）+ ±6% 涨跌停。**不采纳**语义去重与同极性边际递减。

### 4.4 周 K 聚合（用户已确认主图为周 K）

| 字段 | 取值 |
| --- | --- |
| open | 本周首个交易日的开盘（= 上周收） |
| high | **max(周开盘, 周内每日指数最大值)** |
| low | **min(周开盘, 周内每日指数最小值)** |
| close | 本周最后一个交易日收盘 |
| volume | 当周事件总数 |

> high/low 必须包含周开盘，否则整周持续上涨时周最低价会高于周开盘（验收发现③已修正）。

时间范围切换：**周 K（默认）/ 日 K / 月 K**。日粒度数据保留，用于计算明细。

### 4.5 计算明细（必做，不是可选）

点击任意一根 K 线 → 右侧详情展开，**让用户从事件一路核对到收盘**：

1. 当周每日 `r` 的**三段式分解**：原始收益（Σ事件）→ 涨跌停调整 → 实际收益（clamp 后）。
   例：原始 +8%、涨跌停调整 −2%、实际 +6%。
2. 每条计分事件的原文引用 `quote`、极性、强度、贡献点数。
3. 沉默衰减 / 停牌恢复项（标注来源，无 quote）。
4. 超出同日上限的事件（贡献 0，标注「超出当日上限」）。
5. 软删除 / pending 事件不计分。

> 无维度系数（D19）。同日「按发生顺序取前 8 条」需稳定排序键——**规格缺口，路由 agent 会话定**（occurredAt 只到天，需 seq 或 createdAt 作 tie-breaker）。

这个面板是作品帖里最值钱的一张截图，也是评委信任的唯一来源。

## 5. 未来推演（P2，口径已定 D28，不做算命）

- 输入：近 28 天日收益率 → 均值 μ、标准差 σ；持仓中未来 28 天内到期任务的完成增益之和。
- 中性：当前指数 × (1+μ)^28 + 持仓贡献。
- 乐观/悲观：中性基础上 ±1σ 按随机游走传播 28 天（σ×√28），区间随时间展宽。
- 样本 < 4 周：降级为仅给方向（上行/持平/下行），不给具体点位。
- 前端纯函数，不经过模型；界面必须标注「这是推演，不是预测」并显示不确定性。
- **优先级 P2**（有余力再做），作品帖卖点不写推演，避免承诺未实现功能。

## 7. 前端优先，后端倒推

用户已确认顺序：**先敲定前端内容 → 根据前端需要制作后端**。

后端最终只剩一层皮：

- **唯一的服务端职责：转发模型请求。** 因为 API Key 绝不能进前端（公开站点，写进 JS 三分钟被人抓走刷爆账单）。
- Key 放 Qoder Sites 的 Secret（官方说明 write-only、不可回读），由 function 代理调用。
- 或走 Sites 的 `qoder` 后端能力直接调 Qoder Cloud Agents，免密钥，但扣自己账户 Credits。
- **数据默认只存用户浏览器**（IndexedDB / localStorage）。云端同步做成可选项（P2），且需先确认账号档位支持 database（P6）。
- 除此之外没有后端。

Sites 后端可开通能力（已核实）：`database`、`functions`、`storage`、`qoder`。
注意：个人 Free 版只支持静态部署，database 与 storage 不支持。

## 8. 冷启动：第一屏必须有内容

自己用三天只有十条事件，曲线是空的，作品看着像半成品。

- 内置**预置 90 天「样例人生」**，完整周 K 与事件流（研报为 P2，样例不依赖它）
- 顶栏一键切换「看样例 / 看我自己」
- 评委不想打字也能立刻看懂产品
- 样例数据最好取自真实经历（P3 待团队提供），比编的有说服力

## 9. 额度、降级与安全

| 风险 | 对策 |
| --- | --- |
| 每次对话都扣 Credits | 抽取结果缓存，同一句话不重复扣费；限频 |
| 额度耗尽 / 限流 → 作品白屏 | **熔断降级到预置样例数据**，图照样能看，绝不报错白屏 |
| 演示时烧额度 | 演示模式用预置抽取结果，零消耗 |
| Key 泄露 | 只放服务端 Secret，前端永不接触 |
| 隐私（日记级数据） | 默认本地存储；明确告知调用模型时内容会发给模型服务 |
| Sites 用量上限 | 官方说明达上限可能临时限制公开访问，需留缓冲、避免依赖高流量 |

参考量级：简单问答 1–3 Credits，生成文档 10–15，复杂多轮带工具 20–50；沙箱按 running 秒计费约占 5–10%。

合规：Sites 的 AI 生成内容标识按国内要求**不可移除**，不要试图去掉。

## 10. 价值观硬约束（评委会问）

把人量化成分数天然会强化自我否定，尤其学生群体。产品规则写死：

1. 休息不扣分，设「停牌恢复」机制（D20–D24）
2. 指数只度量行为，**不评判人格**；情绪表达记录但不计分（D18）
3. 下跌的文案永远是「波动」，不是「你不行」
4. 不做排行榜、不做社交比较（避免把自我度量变成攀比）
5. 推演标注不确定性，不做命运承诺

## 11. 技术选型

| 层 | 选择 | 理由 |

| 形态 | 单页静态站 | 评委点开即用，Qoder Sites 部署最稳 |

| 存储 | IndexedDB / localStorage | 本地优先，隐私卖点，免后端 |
| 服务端 | Sites function（仅模型代理） | Key 隔离 |
| 部署 | Qoder Sites，公开访问 | 赛事硬性要求 |
