# 队友上手说明（一页纸）

## 这是什么
2026 Qoder 高校创造力大赛参赛作品。把人当一支股票：通过对话录入事件与任务，
引擎算出「个人成长指数」，用周K线等可视化即时呈现，并能推演未来。
竞品卖「被理解」（情绪陪伴），我们卖「被度量」。

## 分工
- **你（队友）**：idea、视觉方向、试玩挑刺、作品帖、截图收集、拍板产品决策
- **实现者**：一人 + Qoder 完成全部代码与部署
- 三个 Qoder 会话并行：前端精修 / agent 逻辑 / 独立验收

## 东西在哪

## 你怎么参与
1. **描述视觉**：把配色/字体/质感/布局想法说清楚，由实现者转进前端会话。不要自己改代码。
2. **拍板决策**：维度划分、情绪是否计分、衰减率等开放项，由你定。结论在飞书群留一句。
3. **试玩挑刺**：打开 Sites 链接亲自走一遍，用验收会话的门禁清单挑问题。
4. **写作品帖**：按 `docs/submission/post-outline.md` 的五部分写，11/27 前发。
5. **收截图**：开发过程截图边做边丢进 `assets/screenshots/`。
